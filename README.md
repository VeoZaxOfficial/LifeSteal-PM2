# LifeSteal

A LifeSteal plugin from VeoZaxSMP upgraded to Lv2.0 by VeoZax for PocketMine-MP Legacy API 2.0.0

## Commands
- `/lifesteal <set,remove,worlds,lbspawn,addowner,removeowner,owners>`
- `/safezone <pos1,pos2,save,remove,info>`
- `/share-heart <player> <amount>`

## Install
Drop the `.phar` into your server's `plugins/` folder and restart the server to activate the plugin.
Download From Here: https://www.mediafire.com/file/gyx248k8tnkthti/LifeSteal-PM2.phar/file
